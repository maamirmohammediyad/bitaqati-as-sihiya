[1.0.0] — Initial Release

This release represents the initial version of the backend prepared for the Bitaqati As-Sihiya project evaluation.

Included

- Authentication and account management.
- Patient and guardian services.
- Hospital and hospital staff management.
- Medical information and medical records.
- Medication-related services.
- Emergency-related services.
- QR code-related services.
- Account verification and recovery.
- API integration with the mobile application and web dashboard.
- Role-based access and protected API endpoints.
- Notification and storage service integrations.

Technical Stack

- PHP 8.2+
- Laravel 12
- Laravel Sanctum
- PHPUnit
- Laravel Pint
